# Discovery brief — Example App

**Date:** 2026-09-15

## Theme or starting point
Open search within "personal productivity" for a solo developer. This file is an illustration
of what a filled brief looks like; the rest of `_example` is untouched templates.

## Founder constraints
- Team: solo, skills: SwiftUI, basic design, no backend
- Time to first TestFlight: 3 weeks
- Budget for validation: $150
- Existing audience or distribution: none

## Exclusions
- Regulated categories (medical claims, finance, kids)
- Anything Apple ships natively in iOS 26 (Reminders, Notes, Journal, Passwords)
- Apps that require a backend team or real-time infrastructure

## Success definition for this search
An opportunity scoring >= 3.5 with monetization evidence, buildable in 3 weeks.
